# API reference

The stable, documented surface of **cellpy-core** is the curated set of names
re-exported from `cellpycore` (see `cellpycore.__all__`). Narrative guides live
under [User guide](../user-guide/standalone-use.md) and
[Specifications](../specifications/harmonized-raw.md); this section is generated
from source docstrings via [mkdocstrings](https://mkdocstrings.github.io).

!!! note "Submodules"
    Other packages (`cellpycore.units`, `cellpycore.metadata`, `cellpycore.legacy`,
    …) are importable but not part of the guaranteed top-level API. Use the
    [Public API](public.md) page for supported symbols.
